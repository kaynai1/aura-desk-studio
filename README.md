# AURA 双屏工坊

一款零依赖、开箱即用的**双屏桌面美化工具**。全部功能由一个 HTML 文件驱动，可在浏览器直接运行，也可通过 Electron 打包为 Windows 便携版 .exe。

![平台](https://img.shields.io/badge/platform-Windows%20%7C%20Browser-blue)

## ✨ 功能

### 壁纸
- **算法壁纸引擎**：极光 / 晨雾 / 落日 / 星野 / 极简 五种风格实时生成
- **跨屏全景壁纸**：一张壁纸无缝铺满双屏
- **动态效果**：缓慢漂移 / 星火粒子（逐帧动画）
- **昼夜自动氛围**：按 晨/昼/暮/夜 自动调整色调与压暗
- **自动轮换**：每 60 秒 / 5 分钟随机换壁纸
- **导出 PNG**：按各屏比例导出高清壁纸，直接设为系统桌面

### 双屏
- 主屏 + 副屏独立比例（16:9 / 16:10 / 21:9 / 竖屏 9:16 / 3:4 / 4:3）
- 小组件跨屏拖拽、自动均衡布局
- 四档自适应：窗口变窄时自动堆叠、面板变抽屉
- Dock 显示策略：仅主屏 / 双屏 / 仅副屏

### 小组件与主题
- 时钟 / 日历 / 待办 / 便签（四色）/ 天气（Open-Meteo 实时数据）/ 系统状态 / 番茄钟 / 倒计时 / 每日一言 / 白噪音（雨声·海浪·篝火，WebAudio 合成）
- 一键主题：午夜蓝调 / 赛博紫夜 / 晨雾青柠 / 暖阳橘 / 石墨极简
- 毛玻璃强度、圆角、组件大小与透明度、性能模式
- **内存优化**：壁纸 1:1 渲染 + 后台自动降为 1/4 分辨率 + 动画底图减半，显存占用最低约 0.7MB
- 专注模式（F）：一键清空桌面
- 锁屏预览（L）、挂机 3 分钟自动锁屏、配置档（最多 4 套）、配置导入导出
- 壁纸收藏夹、桌面右键菜单、桌宠

### 桌面版专属（Windows .exe）— 真桌面集成
- **打开即应用**：启动软件自动把壁纸应用到真实显示器（双屏各一块或跨屏全景，改配置实时同步）
- **桌面小组件悬浮窗**：时钟/待办/便签/倒计时/每日一言以玻璃卡片悬浮在真实桌面上，可拖拽、穿透点击，不影响正常使用电脑
- **副屏投送**：一键把第二台显示器变成全屏仪表盘（大时钟 + 待办同步 + 便签）
- **开机自启动**、系统托盘、设置本地持久化（重启不丢失）

### 快捷键
| 按键 | 功能 |
|---|---|
| `F` | 专注模式 |
| `R` | 随机壁纸 |
| `L` | 锁屏预览 |
| `Esc` | 解锁 |

## 🚀 运行

### 浏览器
直接双击打开 `index.html`（或任意静态服务器）。

### Windows 便携版
从 [Releases](../../releases) 下载 `AURA-DeskStudio-Windows.exe`，直接运行，无需安装。
也可以在本仓库的 [Actions](../../actions) 页面下载最新构建产物。

### 本地开发
```bash
npm install
npm start      # Electron 运行
npm run dist   # 打包 Windows 便携版 exe
```

## 🔨 技术栈
纯原生 HTML/CSS/JavaScript，无框架、无运行时依赖；Canvas 算法壁纸；Electron 仅作壳。
